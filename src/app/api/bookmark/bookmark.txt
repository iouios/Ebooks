[POST] /api/bookmarks

🔍 Description

ดึง bookmarks ของผู้ใช้จาก Firestore โดยใช้ `userSub` (Auth0 User ID)

📥 Request

Method: POST
URL: /api/bookmarks
Auth required: ✅ Yes 
Headers:

    json
  {
    "Content-Type": "application/json"
  }

🔸 Body Parameters

  json
{
  "userSub": "string (Auth0 User ID)"
}

📤 Response (Success)

  json
{
  "auth0_id": "string",
  "book_ids": ["string", "string", "string"]
}


* `auth0_id` → Auth0 User ID ของผู้ใช้
* `book_ids` → Array ของ eBook IDs ที่ user bookmark ไว้

❗️Error Responses

| Status Code | Message         | Description                              |
| ----------- | --------------- | ---------------------------------------- |
| `400`       | Missing userSub | ไม่ส่ง `userSub` มาด้วยใน request body   |
| `404`       | User not found  | ไม่พบ document ใน collection `bookmarks` |
| `500`       | Server Error    | ระบบขัดข้องหรือ Firestore มีปัญหา        |

🗄 Database Schema (`bookmarks` collection)

| Field      | Type      | Description                        |
| ---------- | --------- | ---------------------------------- |
| `id`       | string    | ใช้ `userSub` ของผู้ใช้เป็น Doc ID |
| `book_ids` | string\[] | Array ของ eBook IDs ที่ bookmark   |
