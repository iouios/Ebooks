[POST] /api/ebooks/download

🔍 Description

อัปเดตจำนวนการดาวน์โหลดของ eBook โดยระบุ id ของ eBook ผ่าน query string

ถ้ายังไม่มี document → จะสร้างใหม่พร้อมกำหนด downloads = 1

ถ้ามี document อยู่แล้ว → จะอัปเดตเพิ่ม downloads +1

📥 Request

Method: POST

URL: /api/ebooks/download?id=<ebookId>

Auth required: ❌ No 

Headers:

{
  "Content-Type": "application/json"
}

🔸 Query Parameters
Parameter	Type	Required	Description
id	string	✅ Yes	Firestore Doc ID ของ eBook
📤 Response (Success)
{
  "message": "Download count updated"
}

❗️Error Responses
Status Code	Message	Description
400	Invalid ID	ไม่ได้ส่ง query param id หรือไม่ถูกต้อง
500	Internal Server Error	ระบบขัดข้องหรือ Firestore มีปัญหา
🗄 Database Schema (ebooks collection)
Field	Type	Description
id	string	Firestore Document ID
downloads	number	จำนวนครั้งที่ eBook ถูกดาวน์โหลด
